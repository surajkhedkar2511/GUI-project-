# Java OOP Quiz Application

## 1. Project Overview

The Java OOP Quiz Application is a web-based quiz system developed using HTML, CSS, and JavaScript.

It helps students test their knowledge of Object-Oriented Programming (OOP) concepts in Java through multiple-choice questions.

The application provides an interactive interface where students can enter their name, answer questions, track time, and view their final scores.

## 2. Project Details

- **Project Name:** Java OOP Quiz Application
- **Activity:** CIE-2 Activity-6
- **Subject:** Object-Oriented Programming
- **Application Type:** Web-Based Application
- **Frontend Technologies:** HTML, CSS, JavaScript
- **Quiz Questions:** 10
- **Question Type:** Multiple Choice Questions (MCQs)

## 3. Objectives

- To develop an interactive online quiz application.
- To improve understanding of Java OOP concepts.
- To calculate quiz scores automatically.
- To provide a simple and user-friendly interface.
- To understand JavaScript functions and event handling.

## 4. Technologies Used

### HTML
Used to create the structure of the quiz application.

### CSS
Used to design the interface, colors, buttons, layout, and responsive design.

### JavaScript
Used to manage quiz questions, answer selection, timer, score calculation, and result display.

## 5. Features

1. Student name entry.
2. Welcome screen.
3. 10 Java OOP multiple-choice questions.
4. Four options for each question.
5. Question navigation.
6. Countdown timer of 60 seconds.
7. Progress bar.
8. Automatic score calculation.
9. Final result and percentage display.
10. Restart quiz functionality.
11. Responsive user interface.

## 6. Topics Covered

The quiz includes questions related to:

- Classes and Objects
- Inheritance

- Encapsulation
- Constructors
- Method Overloading
- Interfaces
- Exception Handling

## 7. How to Run the Project

1. Copy the complete HTML source code.
2. Open Notepad or any code editor.
3. Paste the source code.
4. Save the file as `QuizApplication.html`.
5. Select Save as type: All Files.
6. Open the HTML file in Google Chrome or another web browser.
7. Enter your name and click Start Quiz.
8. Answer all the questions.
9. View your final score.

## 8. System Requirements

- Operating System: Windows / Linux / macOS
- Browser: Google Chrome, Firefox, or Microsoft Edge
- Code Editor: Notepad / VS Code
- Internet Connection: Not required
- Additional Software: Not required

## 9. Application Workflow

1. Student opens the application.
2. Student enters their name.
3. Student starts the quiz.
4. Questions and four options are displayed.
5. Student selects an answer.
6. Student moves to the next question.
7. The application calculates the score.
8. Final result is displayed.
9. Student can restart the quiz.
